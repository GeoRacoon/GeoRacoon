Examples
========

Some examples showing how to use the GeoRacoon in a sequence of
geospatial analysis tasks.

Standalone script examples (suitable for direct
download and execution) are available in the `examples/
<https://github.com/GeoRacoon/GeoRacoon/tree/main/examples>`_ folder of the
repository. Script examples have an '*exmpl_*' prefix.

.. note::

   The raster datasets used by these examples are not shipped in this
   repository. They are hosted on Zenodo at
   `doi:10.5281/zenodo.22307203 <https://doi.org/10.5281/zenodo.22307203>`_
   (a concept DOI that always resolves to the latest version) and are
   downloaded automatically on first use, then cached locally for later runs.
